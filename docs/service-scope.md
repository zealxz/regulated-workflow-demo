# 7 日可审计文档工作流自动化冲刺

状态：服务边界已在公开 GitHub 演示中展示；Upwork Project Catalog 已于 2026-08-26 批准并公开可见。当前尚无订单或已验证客户案例。

## 定价

- 国内首两单：固定价 ¥999。
- Upwork 首两单：固定价 $149。
- 获得两个可公开、可验证案例后：¥2,999 / $399。
- 不以免费定制成品换取潜在成交，不低于首单价。

## 固定范围

- 一个数据源（默认本地处理；如接入既有 API，仅限客户自有环境中已批准的接口）；
- 最多 20 份代表性文档或 500 行输入记录，并预先约定要处理的字段/列；
- 一条提取、校验或前后版本对比流程；
- 一个结构化输出和一个明确人工审批点；
- 客户自有/本地运行环境；
- 运行说明、聚焦测试、架构说明、审核指南；
- 验收后 7 天缺陷支持，一次与书面验收不符的限定修正。

## 客户必须提供

1. 一份公开、脱敏或合成样例。
2. 期望输出和一个正确结果示例。
3. 当前人工步骤与最容易返工的规则。
4. 必须保留给人的判断。
5. 如涉及既有 API，提供公开或测试环境文档；凭据仅由客户在自有环境中配置，不通过表单、私信或仓库传递。
6. 一名最终验收负责人。

## 不包含

- 法律、监管、医疗、金融或安全认证意见；
- 保证流程“合规”或模型 100% 准确；
- 绕过登录、付费墙、robots 或访问限制；
- 原型阶段处理未授权生产数据、个人敏感信息或长期 secret；
- 自动对外发送、破坏性修改、金融交易或自主高影响决策；
- 共享白标 n8n 托管、生产运维、7×24 支持、完整 SaaS 或无限修改；
- 第三方 API、模型、OCR、云服务或软件费用。

## 验收

- 对约定样例生成约定格式；
- 支持的错误路径显式失败，不把缺失/失败包装成有效结果；
- 每条证据或变更有稳定标识、来源提示和复核状态；
- 所有高影响输出默认待人工确认；
- 客户能够依据 README 在自有环境复现。
